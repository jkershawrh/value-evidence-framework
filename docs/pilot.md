# 90-day pilot

## Phase 1 — contract and shadow scorecard (weeks 1–3)

Choose Cascade Compression's avoided model calls. Agree on outcome ID, workload boundary, unit
economics, comparison period, safety threshold, and fully loaded deployment cost. Run the scorecard
in shadow mode and record every missing input.

## Phase 2 — counterfactual (weeks 4–8)

Use a phased or matched rollout. Keep demand mix, model quality target, and hardware scope
comparable. Pre-register success and failure criteria. Retain raw aggregates and calculation
version; do not retain prompts or customer-sensitive payloads.

## Phase 3 — portfolio composition (weeks 9–12)

Add Fleet placement and GCL avoided-action claims. Assign shared outcome IDs and contribution shares
before viewing the financial results. Add ledger receipts for provenance. Publish customer and Red
Hat scorecards with the same calculation kernel and different explanatory views.

## Exit criteria

- One claim independently reproducible.
- One observed counterfactual stronger than an expert estimate.
- No outcome attribution above 100%.
- Realization cost includes engineering, operations, enablement, and services.
- Customer reviewer accepts or explicitly disputes every financial input.
- Scorecard can render a negative result without special handling.
